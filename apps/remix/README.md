# @documenso/remix

The main SignFlow web application (monorepo package `@documenso/remix`). Built with [React Router v7](https://reactrouter.com/) and served by a [Hono](https://hono.dev/) server.

This package is part of the SignFlow monorepo and is not meant to be run standalone. Use the root scripts instead.

- Local development: see the root [README.md](../../README.md).
- Architecture overview: see [ARCHITECTURE.md](../../ARCHITECTURE.md).

```bash
# From the monorepo root
npm run dev
```
